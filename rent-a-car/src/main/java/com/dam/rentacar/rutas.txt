RUTAS FRONTEND REACT - OASIS-DRIVE
===================================

AUTENTICACIÓN
/auth/login - Iniciar sesión
/auth/registro - Registrarse
/auth/logout - Cerrar sesión

CATÁLOGO (Público)
/ - Home
/vehiculos - Listado de vehículos
/vehiculos/:id - Detalle vehículo
/vehiculos/disponibles - Solo disponibles
/vehiculos/marca/:marca - Filtrar por marca

RESERVAS (Autenticado)
/reservas - Mis reservas
/reservas/nueva/:idCoche - Crear reserva
/reservas/:id - Detalle reserva
/reservas/:id/cancelar - Cancelar

USUARIO (Autenticado)
/usuario/perfil - Ver perfil
/usuario/editar - Editar perfil
/usuario/cambiar-password - Cambiar contraseña
/usuario/mis-valoraciones - Mis valoraciones

VALORACIONES
/valoraciones/crear/:idCoche - Nueva valoración
/valoraciones/coche/:idCoche - Ver valoraciones vehículo

ADMIN (Solo Admin)
/admin/dashboard - Panel principal
/admin/usuarios - Gestionar usuarios
/admin/vehiculos - Gestionar vehículos
/admin/vehiculos/crear - Crear vehículo
/admin/vehiculos/:id/editar - Editar vehículo
/admin/reservas - Todas las reservas
/admin/valoraciones - Todas las valoraciones

SERVICIOS API (Backend)
POST   /api/usuarios/registro
POST   /api/usuarios/login
GET    /api/usuarios/:id
PUT    /api/usuarios/:id
PUT    /api/usuarios/:id/cambiar-password

GET    /api/coches
GET    /api/coches/:id
GET    /api/coches/disponibles/lista
GET    /api/coches/marca/{marca}
GET    /api/coches/precio?min=&max=
POST   /api/coches (Admin)
PUT    /api/coches/:id (Admin)
DELETE /api/coches/:id (Admin)

POST   /api/reservas
GET    /api/reservas
GET    /api/reservas/:id
GET    /api/reservas/usuario/:id
DELETE /api/reservas/:id
PUT    /api/reservas/:id/finalizar

POST   /api/valoraciones
GET    /api/valoraciones
GET    /api/valoraciones/:id
GET    /api/valoraciones/coche/:id
GET    /api/valoraciones/coche/:id/promedio
PUT    /api/valoraciones/:id
DELETE /api/valoraciones/:id
