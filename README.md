# Oasis-Drive

**Oasis-Drive** es una aplicación web de alquiler de vehículos que permite a los usuarios consultar vehículos disponibles y gestionar sus reservas a través de una plataforma intuitiva y organizada.

## Tecnologías

**Frontend**
- React 19
- JavaScript
- Vite
- React Router
- Tailwind CSS 3

**Backend**
- Java 21
- Spring Boot 3.5
- Spring Security
- OAuth2 Resource Server
- Spring Data JPA

## Funcionalidades

- Consulta y visualización de vehículos.
- Gestión de reservas de alquiler.
- Gestión de usuarios y autenticación.
- Validación de datos y reglas de negocio.
- Comunicación entre frontend y backend mediante API REST.
